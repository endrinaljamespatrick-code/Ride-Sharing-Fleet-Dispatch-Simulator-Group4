# Ride-Sharing-Fleet-Dispatch-Simulator-Group4
CPAS 312L - Data Structures and Algorithms Laboratory

## Project Overview
C++ console-based Ride-Sharing Fleet Dispatch Simulator for our course project.
All data structures and algorithms are manually implemented; no STL containers are used.

## Included Source Files
‑ Group4_Task1.cpp → Linear & Non-Linear Data Structures
‑ Group4_Task2.cpp → Sorting & Searching Algorithms
‑ Group4_Task3.cpp → Greedy Algorithm (Dijkstra’s Shortest-Path)

## Notes
‑ No separate .h header files
‑ Designed for console-only output
